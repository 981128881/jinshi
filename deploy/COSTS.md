## 查价入口（别问别人，自己点）

1. **服务器到期日 / 续费价** → 阿里云控制台 → 费用 / 续费管理  
2. **域名到期日 / 续费价** → 域名控制台 → `cr20.help` → 续费  
3. **小程序认证到期** → mp.weixin.qq.com → 设置 → 微信认证  
4. **若开了支付** → pay.weixin.qq.com → 账户中心 → 费率

主机与域名常量见 [HOSTS.md](./HOSTS.md)。
